Aktivasi di aplikasi Windows:

Buka KACA.ID → Cloud Account & Lisensi, masuk dengan email/password, masukkan kode lisensi yang diberikan Super Admin, lalu beri nama booth.

Remote Booth

Akses ke jendela aplikasi KACA.ID, bukan seluruh desktop komputer. Operator booth harus menyetujui akses hingga 15 menit dan dapat mencabut izin kapan saja.

Menunggu persetujuan operator booth.

Remote hanya aktif setelah izin lokal. Tindakan pemilik akun dicatat, dan input tetap dibatasi pada jendela aplikasi.
